EQ Cruncher is an equation evaluator for GameMaker Studio 2.3. Crunch basic expression just like a calculator, or put together more complex equations with independent and dependent variables!

# Features
- Expression: a struct that can handle custom equations.
- BinaryTree: used to evaluate the expression
- Various demos showcasing how to plot various types of equations.
- Supported symbols:
https://github.com/nandbolt/EQ-Cruncher/blob/8a4e582ee395c08d432a44a320cc5f4bd0790326/scripts/scrEQC_Enums/scrEQC_Enums.gml#L1-L40

# How to use
1. Create the expression.
2. Set the symbols.
3. Evaluate!

https://github.com/nandbolt/EQ-Cruncher/blob/8a4e582ee395c08d432a44a320cc5f4bd0790326/objects/oEQC_DemoBase/Create_0.gml#L112-L122

# Demos
Included are various demos showcasing how you can turn an expresion into a plot of points. There are various types of equations showcased, from the standard y = x, to polar and even scalar and vector fields!
